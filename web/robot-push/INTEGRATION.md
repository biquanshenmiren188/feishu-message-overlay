# 接入状态

v33已通过本机唯一飞书接收连接→签名发布→服务器公钥验签→公开网页的自然消息验证。部署与边界以 [DEPLOYMENT.md](DEPLOYMENT.md) 为准，协议见 [PUBLISHER-DESIGN.md](PUBLISHER-DESIGN.md)。

只有已明确批准公开的机器人消息可开启此路径；默认源码与发行包不携带配置。正式私钥不得交给服务器、模型、终端、日志或源码归档。合成验签使用独立临时测试钥，服务器生产只注册实际发布公钥。

页面默认实时模式，连接失败时显示未连接，不注入模拟消息。只有显式 `?mode=demo` 使用虚构预览数据。静态开发时可使用仓库内离线空feed.json，它不代表正式数据已接入。
