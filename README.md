# 飞书消息小窗

轻量 Windows WPF 小窗，通过飞书官方 Node SDK 长连接接收指定群的机器人新消息。白底黑字、默认微软雅黑，正文前两条逻辑文本行加粗，HTTP/HTTPS 链接可点击。普通成员消息不显示或响铃。

## 使用

- 正常启动紧贴当前屏幕工作区右上角，外边距为0。归位图标按实际消息高度调整至约三条；长消息超过屏幕时正常滚动，不裁切正文。窗口可拖动、缩放。
- 左上蓝灰开关控制逐条定时阅读，默认每条 15 秒，点击秒数可改为 1–300 秒。新消息不打断正在阅读的条目。手动滚动暂时暂停但保留开关开启；连续10秒没有滚轮、滚动按键或滚动条操作后，从当前可见条目重新开始完整停留时间。连续操作延后恢复，关闭开关或隐藏窗口取消恢复计时。队尾没有下一条时停止计时，隐藏到托盘时暂停阅读计时。
- 右上三根递增高度的小竖条显示真实连接状态（不是信号强度测量），详细原因见提示或设置。喇叭、置顶、设置、隐藏图标常驻；无机器人名称、ID、大标题或底部状态栏。
- 背景透明度 60–100%，仅白色背景变透明，文字、链接和图标保持不透明。设置窗口始终不透明。
- X 隐藏到右下角托盘，继续接收与响铃；真正退出在托盘菜单。主任务栏没有窗口按钮，同一用户只运行一个实例。
- 开机启动开关默认关闭，由用户打开后注册当前用户启动项。保存的应用配置可在启动时恢复连接。
- 声音只有开关，跟随系统音量。可导入有权使用的本地 WAV/MP3（不超过 2 MB）。不附带第三方音频，不修改系统音量。

## 构建与运行

置顶开启且窗口可见时，操作前台浏览器会让小窗临时退到其后，连续5秒无输入后恢复置顶，不抢焦点。仅在受支持浏览器位于前台时，每500毫秒读取一次系统最后输入时间戳和前台窗口；不读取按键、网页、URL或窗口标题，不安装键鼠钩子。时间戳包括鼠标移动；恢复精度受500毫秒检查间隔影响。支持Chrome、Edge、Firefox、Brave、Opera、Vivaldi进程，未识别的浏览器不启用此行为。

浏览器拖动同样按5秒闲置恢复；其他程序的顶层窗口移动/缩放结束约300毫秒恢复。小窗、设置和托盘操作排除；手动关闭图钉、隐藏或退出停止浏览器检查。只修改小窗层级，不改变窗口位置尺寸或暂停消息接收。异常遗漏拖动结束事件时，仅在让位期间每2秒检查一次窗口移动状态。

同批通知及两秒内密集通知合并声音；每条消息仍正常显示，不排队补响。阅读计时、闲置恢复和打开声音开关不触发旧消息重播。

要求 Windows x64、.NET 10 Windows Desktop Runtime、Node 22 或兼容版本；构建另需 .NET 10 SDK。

```powershell
npm ci --prefix bridge --ignore-scripts
npm test --prefix bridge
./scripts/build.ps1
# artifacts/app/FeishuMessageOverlay.exe
```

默认生成依赖已安装 .NET 和 Node 的轻量版，不携带它们的运行时。`-SelfContained` 可携带 .NET 运行时，Node 仍需安装。构建脚本仅在发行副本中移除未运行使用的 TypeScript 声明、备用 SDK ES 构建和类型包，保留运行依赖与许可证。程序不会静默安装软件。

当前是普通 EXE/ZIP，不使用 Windows 通知中心、MSIX、Windows SDK 或通知读取授权。源代码和发行包不含应用凭证、私有群配置或消息。

## 配置飞书

使用自己的企业自建应用，启用机器人，取得应用身份权限 `im:chat:read`、`im:message.group_msg.include_bot:read`，订阅应用身份事件 `im.message.receive_v1`，接收方式选择长连接。按租户要求审核发布，将机器人加入明确授权的目标群。最多配置五个准确群 ID，可进一步配置机器人发送者白名单。

网页登录不等于 API 授权。外部群另有认证、对外共享和发布要求；仅在确需且获准时允许机器人加入外部群。现有机器人、尤其自定义 webhook 机器人是否可被接收，必须在目标群用自然新消息验收，不能仅凭连接成功承诺。

设置中提供官方扫码创建与受保护的本地凭证输入。已有应用不要重复创建。密钥通过私有标准输入管道交给 SDK，不作为命令行或环境变量传递。默认只用于当前会话；用户明确选择并提交后才使用当前 Windows 用户 DPAPI 加密保存。不要通过聊天发送密钥。

官方资料：[接收消息事件](https://open.feishu.cn/document/server-docs/im-v1/message/events/receive?lang=zh-CN)、[外部群机器人](https://open.feishu.cn/document/develop-robots/add-bot-to-external-group)。

## 隐私与边界

先按群 ID、发送者类型及可选发送者 ID 筛选，再解析正文。窗口只显示正文与时间；内部 ID 用于过滤和去重，不在界面显示或常规日志中输出。消息仅在有界内存中保留，最多 100 条、30 分钟，每条最多 16,000 字符；过长或不支持内容有明确提示。卡片仅显示官方事件实际提供的可读文字，不保证附件或像素级还原。

暂停、失去连接权限及退出清空消息；清空不操作飞书或系统通知。重连使用新时间基线，避免历史重放。新消息只触发增量界面更新，列表虚拟化；正常运行不定时写验收回执，不保存正文。偏好启动加载一次，用户修改后合并保存。配置凭证与群选择由明确配置动作保存。

诊断计数只在内存。明确执行 `FeishuMessageOverlay.exe --export-diagnostics <输出文件>` 才导出一次非正文状态、群计数和布局信息；导出文件含私有群 ID，不应提交源码。`--diagnose-saved <输出文件> bot-only` 仅用于已有合法配置的机器人元数据诊断。

## 验证

构建脚本运行核心检查、真实 WPF 窗口和私有桥接的无凭证合成检查，包括真实 DispatcherTimer 的 5 秒与 15 秒逐条推进。它不等于每个真实目标群已验收，也不证明物理音响已听见。具体范围见 [SOURCE-VALIDATION.md](SOURCE-VALIDATION.md)。Windows CI 使用无凭证测试，不连接私人群。
