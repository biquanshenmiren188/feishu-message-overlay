# 屏蔽币种母子菜单 · 2026-10-23

## 行为
“屏蔽币种”作为母菜单，默认进入跨三端已保存币种清单；电脑消息、行情卡片、手机推送为缩进子菜单。子菜单继续独立维护币种、交易所、左右腿、现货、OI、其他选项和真实拦截记录。电脑静音与隐藏仍独立，手机预览保留。

母菜单新增全部/三端已屏蔽/部分屏蔽/仅静音筛选，搜索、勾选当前列表、清空选择和批量屏蔽三端。仅静音筛选指电脑具有启用静音币种规则且无匹配隐藏币种规则。状态只汇总币种规则，不预测其他条件的最终判定。按币种+交易所作为行标识。批量按交易所分组、每次最多30币，顺序复用既有幂等API，不扩大范围；成功项取消选择，失败中止并保留未完成选择，可查看逐端结果重试。母菜单添加仅提供三端保存，回车同样走三端API。子菜单添加仍可以仅加入本渠道草稿。

一键操作记录在母菜单折叠展示，实际拦截记录在相应子菜单展示。菜单切换不提交规则，跨端操作仅合并指定目标，保留其他草稿。
