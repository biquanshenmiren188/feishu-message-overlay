# 已屏蔽卡片查看入口

用户要求能查看 BOT 卡片区域被规则屏蔽的卡片。「已屏蔽 N 张」现在是独立按钮，在电脑、手机网页和 PWA 均可点击。弹窗复用当前线上卡片渲染器，显示币种、方向、费率、结算周期、盘口和充提等原有信息；标明本方案规则屏蔽或行情卡片接收已关闭。只读查看不改变屏蔽规则，不增加主列表 ACTIVE 数量，不发送通知。

仅显示当前推送码经服务端确认为 hide 的当前/保留卡片；未知判定不纳入屏蔽数。未绑定仍是公共浏览；未载入、401/403、规则过期时禁用入口并清空已打开窗口中的卡片。切换推送码清空并关闭旧窗口，迟到响应仍受现有身份校验约束。

窗口中的「管理」复用原币种规则弹窗，修改后仍须明确保存。Escape/关闭返回入口焦点。预览数值沿用 10 秒批次，原30秒失效截止仍生效，规则解除后从预览移除并恢复正常列表；不会因为查看而延长卡片寿命。窗口显示最近快照提示，不能把预览当成当前可执行报价。
