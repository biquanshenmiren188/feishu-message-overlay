## 服务边界

独立 `radar-push-center` 服务（回环 18887），API `/radar/push-center-api/`。SQLite 位于 `/var/lib/radar-push-center/center.sqlite3`，只保存稳定 profileId 对应的名称、版本和中心操作记录。旧身份注册表继续作为配对、创建、令牌、订阅的权威来源；中心通过白名单适配接口使用它，避免复制身份或迁移旧凭据。旧 PWA、桌面规则、报警数据库/密钥与设备位置都保持。

名字写入有版本冲突校验和请求编号幂等；Bark 写入沿用报警服务的版本和幂等协议。浏览器遇到不确定结果保留原请求供重试，切码后丢弃旧响应。新码创建沿用原会话请求编号，避免网络失败重复生成。手机端切码仍走已验证的订阅转移、恢复日志和 worker 配置流程。

中心不存 token、完整推送码、订阅 endpoint 或 Bark Key。码仅鉴权后按请求展示，所有 API 禁止缓存，访问日志关闭。Bark Key 只通过 HTTPS 提交，原报警服务负责加密保存。测试通知须用户点击并确认，检查中使用隔离假数据，不主动发送真实通知。
