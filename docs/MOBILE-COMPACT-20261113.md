# 手机紧凑布局（2026-11-13）

手机顶部七个入口改为两排直接显示，消息设置改为紧凑渠道栏和屏蔽列表，批量选择按需展开；报警卡片压缩留白，保留来源、价格、条件、状态、提醒频率及操作。

所有布局规则限定在 700px 以下。消息设置适配脚本仅移动现有说明节点、添加折叠和批量展示入口；桌面恢复原节点位置。没有修改报警引擎、备用源、单位换算、推送调度或账户配置。

验证：3 号 Chrome 的 320/393px 手机视口、1440px 桌面视口；两排导航、消息搜索、渠道切换、批量入口；隔离报警编辑保存，勾选备用源和持续提醒保留。393px 报警卡片高度约 165px，模拟备用源与 3 秒延迟刷新前后卡片坐标不变。既有 20 项前端测试和 98 项后端测试通过。浏览器视口验证不等于 iPhone 真机验证；本次不发送真实通知。

发布使用 `prepare-mobile-compact.py` 对当前线上 HTML 添加独立样式/适配脚本，再由 `deploy-mobile-compact.py` 克隆当前静态版本定点替换。部署核对当前版本、原文件哈希、服务进程、后端文件、报警配置、绑定和推送状态；失败回滚静态入口。线上发布信息在验收后补充。
