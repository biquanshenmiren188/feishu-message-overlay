# 币种管理手动保存与电脑推送选择

2026-10-24：网页行情卡片只保留“管理”，删除重复的外部“屏蔽三端”。管理内“屏蔽三端”只填入全部交易所范围的草稿，点击“保存修改”后才通过 edit-coins 保存；关闭或 Escape 不提交。

卡片管理与消息设置的币种管理矩阵均合并为“电脑推送”一列，只提供“电脑屏蔽 / 电脑静音 / 未设置”。主动选择屏蔽或静音时移除同币种同交易所范围的另一电脑规则；未设置移除两类规则。其他范围和渠道保持。旧双开或停用数据载入时按屏蔽优先显示，但未经用户修改不隐式改写；底层精确 before/after、部分失败和原 requestId 重试保持。屏蔽三端会选择电脑屏蔽并清除该全部交易所范围的静音。

验证：182 项 Node 检查通过，无跳过，其中 30 个真实 Chromium 场景覆盖两个弹窗的三选一转换、无保存不写、关闭丢弃、精确保存、失败重试、读取权限与身份切换、旧规则保留以及 1280px/393px 布局。浏览器测试完全拦截网络，不使用真实规则或通知。

运行浏览器检查需可用的 Playwright/Chromium；设置 NODE_PATH 指向已有包目录，并设置 RADAR_BROWSER_TESTS=1，使依赖缺失时失败。RADAR_TEST_SCREENSHOT_DIR 可指定截图输出目录。

发布脚本 scripts/deploy-card-manual-save.py 只替换六项静态资产，从锁内实际 current 克隆，核对目标基线哈希并保留其他文件。刷新 policy/manager/CSS 与设置页缓存引用，更新 BOT 内容哈希 bundle 和独立 PWA fallback。核对所有运行中服务 PID、各码规则及订阅保持；失败只回滚代码，不恢复旧用户数据。
