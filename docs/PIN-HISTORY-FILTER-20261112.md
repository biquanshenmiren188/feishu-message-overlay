# 屏蔽后置顶补足与三端修复（2026-11-12）

旧实现仅存原始5条、当前被屏蔽后不再拉历史，导致置顶区消失。现改为内部保存有界200条源候选，按当前个人规则先过滤，再取最多5条显示；不把屏蔽消息重新显示。实际可用记录不足5条时展示已有记录，历史不足不虚构。网页当前置顶被屏蔽仍独立读取历史，旧在上、新在下，默认到底部。

修复聚集消息混合60/180秒窗口解析；逐组判定，有一组允许则整条可见，全部隐藏才隐藏。普通消息30条、用户规则和手机订阅不变。置顶保持原有卡片和自然高度，仅增加内部滚动；手机置顶也保持在普通流顶部。

桌面通过既有签名控制协议显式请求同一过滤结果，空码全部接收，有码按个人规则。历史不入普通队列、不补声音；窗口复用原卡片模板，当前卡片在最下，之前4条可向上滚动。原生窗口新增实际测试覆盖：当前隐藏仍有5条、最新在底、独立滚动、初始历史静音。

验证与正式部署/安装版本在验收完成后补充。本次代码继承PR #70，不恢复已撤回的大卡片UI或普通流回灌。
