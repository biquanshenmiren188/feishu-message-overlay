# 报警内容操作入口（2026-11-14）

按用户选择 B，只在现有操作区增加「报警内容」，电脑和手机保留原列表/卡片结构；编辑、删除及其他界面保持原样。

- 每条规则保存独立 `alarmContent`（纯文本，最多 1000 字），空白恢复默认通知正文。自定义文本位于通知正文开头，系统仍保留币种标题、触发价格、实际行情来源及时间。
- 内容更新使用独立 `content` 操作，校验推送码归属、乐观版本和幂等请求；不修改报警配置其他字段、触发状态、设备绑定、发送队列及 30 秒计时。断流时也能保存文字。
- 一轮通知在生成时固定正文，全部设备使用同一版本；保存后的文字从下一轮生效，已排队或正在发送的当轮通知保持原内容。历史记录不被改写。
- 普通报警编辑未提供 `alarmContent` 时服务端保留已有内容，兼容旧编辑页面。
- 不变更备用源选择、倍率币换算、触发判断、强提醒策略和逐设备发送间隔。健康接口版本 14，`alarmContent=true`。

- 内容专项：字段限制、跨推送码隔离、版本冲突、幂等、断流保存、清空、配置/状态/绑定不变、普通编辑保留内容。
- 3 设备 × 3 轮真实 sender（HTTP 边界模拟）：0/30/60 秒触发，轮中编辑不导致设备正文不同、不提前重发。
- 实时时钟 3 设备 × 3 轮：间隔 30.009～30.012 秒；模拟一台超时，其余两台正常，不阻塞、不重复。未向真实手机发验收通知。
- 272 组倍率币/交易所方向场景使用自定义正文，包含勾选备用源切换、价格单位换算和两设备 30 秒重复发送。
- Chrome 3 号隔离页面：1440px 电脑、393px 手机、320px 窄屏；编辑保存回显、取消不写入、普通编辑后保留、刷新保留、手机清空恢复默认均通过。手机为浏览器响应式验收，非 iPhone 真机。

## 发布

使用 `scripts/deploy-alarm-content.py`：固定当前版本与文件哈希、运行服务器回归、私有线上数据副本启动演练、原规则/加密设备绑定摘要检查、原静态资源复制、原无关服务 PID 检查，再切换代码。仅重启报警服务。失败时切回原代码，不还原旧用户数据。实际源码 SHA 和上线结果在后续发布记录补充。
