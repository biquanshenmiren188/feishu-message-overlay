# 报警内容实时预览

仅在“报警内容”弹窗输入框下增加手机通知预览，显示 Bark 标题和展开后的正文。编辑输入即时更新，无需保存即可预览，不调用通知接口、不生成队列、不发送手机通知。

使用打开弹窗时已核对的行情样本和服务器时间，固定这一份预览上下文，避免后台轮询让编辑区价格、时间跳动。当前行情不可用时明确标注按设定价示例，不把过期价格当作实时值。当前行情预览仅表示内容格式，未达到条件时不表示报警已触发，实际正文以触发时为准。

预览和 Python 后台使用相同动态字段、必要字段补齐和单次替换规则；测试将 JS 渲染结果与实际 Python render_content 逐字比较。包括默认、清空、自定义、删字段、备注、HTML 原文、勾选备用源和 1000PEPE 已换算价格，避免重复倍率换算。未知字段显示错误提示；全部内容用 textContent 展示。

6 项内容与预览测试通过；3 号浏览器隔离环境 1440/393/320px 检查默认展开、编辑同步、保存刷新回显及无横向溢出。仅操作合成规则，未发通知。手机为响应式视口验证。

静态发布由 scripts/deploy-alarm-preview.py 保护：仅增量更新 index.html、app.js、content.css、新增 content-preview.js；保留线上导航和其他 UI 补丁，校验绑定与规则摘要、后台路径、所有推送服务 PID、PWA 状态和无关静态文件。后端无需修改或重启。
