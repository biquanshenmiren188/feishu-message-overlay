# 价格报警与统一推送码入口

用户要求按币种价格设置 Bark 报警，新入口命名「报警设置」，推送码管理移到全站页头右上角，外观沿用现有雷达 UI。消息筛选与价格报警独立，各推送码隔离。

## 功能与边界

- `/radar/robot-push/alarms/`：上穿、下穿、进入/离开区间，最新成交价或永续标记价格；单次/重复、连续采样确认、冷却、恢复幅度、有效期、备注、普通/时效性通知。
- 六家交易所 Binance、Bybit、OKX、Bitget、Gate、Aster；当前为 USDT 现货/永续。精确原始 symbol 与报价单位，不擅自去除千倍前缀。缺少行情时不补零、不借用其他所价格。
- 官方 REST 快照按交易所/市场共享，活跃市场目标约 2 秒发起下一次采样（外加响应时间）；空闲目录 60 秒更新。不是逐笔交易监听，两次采样之间的短暂穿越可能漏掉。12 秒新鲜度、来源时间单调检查；Gate 无价格事件时间时显式采用本次官方请求观测时间。
- 首个快照已满足条件时默认等下次穿越，可选择立即提醒。断线/重启后不补造历史事件，可选择恢复提醒并在通知中标记。持续确认是连续有效采样确认，不声称还原每笔交易。
- 重复规则需恢复到阈值外的恢复带，重新穿越并满足冷却；仅冷却结束不产生新事件。单次触发与发送重试分离。
- 一码一台 Bark，跨码重复 Key 拒绝；先在旧码解绑再到新码绑定。网页切码不迁移 Bark；原 PWA 本机切码与恢复日志保持原逻辑。
- Key 只支持 `api.day.app`，使用 POST `/push`，Fernet 加密落库；凭据不进响应、访问日志或仓库。服务端加密密钥位于私有状态目录，备份应连同数据库安全保存。
- 新事件/状态/队列同一 SQLite 事务；配置修改使用 revision 与不可变 requestId。网络结果未知保留原操作重试，最多保留 7 天幂等结果。
- 单事件发送时效 120 秒；429/5xx 有界退避，最多 3 次。请求超时/响应不明标记「结果未知」，不盲发；进程在发送中重启同样标记未知。HTTP 接受不能证明实体手机显示。
- 暂停/删除/编辑/换设备取消尚未发送的队列；已发起的 HTTP 请求无法撤回。记录保留 30 天、页面显示最近 100 条。

## 架构

`现有推送码 bearer → 原推送后端只读认证 → 独立 radar-alarms → 行情/规则/SQLite outbox → Bark`

`/radar/alarms-api/` 经现有域名 nginx 访问控制代理到回环 `18886`。旧 `robot-push` 与 `radar-webpush-test` 不改代码、不重启；新服务使用现有 Python venv 中的 cryptography。生产状态 `/var/lib/radar-alarms`，源代码 `/opt/radar-alarms/releases/<commit>`，`current` 为链接。

页头共用 `shared-account.js/css`，迁移现有通知管理控件，不复制另一套认证。完整推送码默认掩码，主动显示/复制；退出当前网页身份保留原 PWA 设备 token 与云端运行。未保存草稿在切码前提示。修复旧 `radar-profile-changing` 延后触发覆盖新方案的事件顺序。

## 验证与发布

- Python 35 项：价格边界/Decimal、持续确认、恢复带、冷却、过期/乱序、缺失、跨码隔离、并发幂等、加密、URL 限制、队列取消、重启未知、API 认证。
- 现有手机推送 23 项：Android/iOS 协议、订阅转移、占用保护、恢复日志、草稿与迟到响应。调整两个显示预期为掩码。
- 独立真实 Chrome（合成 API/设备）：1440、393、320px；新增/复制/暂停/筛选/绑定、请求重试、切码隔离，原消息设置页面入口迁移，截图与无横向溢出/导航不覆盖正文检查。没有调用真实 Bark 发送接口。
- 六家十二个市场在生产主机只读探测成功；Aster 部分现货最后成交时间较旧，新鲜度保护会暂停该价格判断。
- 生产部署脚本 `scripts/deploy-price-alarms.py`，默认仅预检；候选由 `prepare-price-alarms.py` 从实际线上 HTML 增量生成。持 guard.lock 验证源码、候选哈希、旧文件哈希、既有服务 PID 和用户设置/订阅摘要。克隆 current 保留无关产物，同步 PWA fallback，仅新增报警服务并 reload nginx。
- 新服务上线不自动创建用户规则、不绑定设备、不发送真实测试通知。Bark 绑定及实体手机显示需用户在页面完成一次验收。
- 回滚静态链接、PWA fallback、nginx 配置及报警服务代码；不回滚用户数据库或密钥。确切提交/发布目录在后续发布记录中登记。

官方依据：Bark `https://github.com/Finb/Bark/blob/master/docs/tutorial.md`、`docs/params.md`；各交易所公开 ticker/mark-price API。Bark 的 `ttl` 控制历史保存，不用于本服务 outbox 过期；`id` 可辅助受支持客户端替换相同通知，但不承诺网络层 exactly-once。
