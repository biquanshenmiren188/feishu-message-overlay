## 变更范围

没有改变原有脚本字节、链接、文字、控件、顺序、设置、业务逻辑或运行时。PWA 的 manifest、启动地址、worker、scope、订阅及缓存身份保持原样。新增链接使用绝对路径，不受 BOT/PWA 的 `base` 或相对 URL 影响。
