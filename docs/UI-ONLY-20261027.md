## 变更范围

以下三个入口均在 `head` 结束前追加同一条、且仅一条引用：

```html
<link rel="stylesheet" href="/radar/radar-ui-v2.css?v=20261027-ui2">
```

- `web/robot-push/index.html`：BOT 源码入口。
- `web/robot-push/settings/index.html`：独立消息设置源码入口。
- `web/push-test/index.html`：保留的 PWA 回退模板。`deploy_live.py` 仍有直接上传这个模板的历史路径，因此同步引用，避免以后恢复模板时漏掉样式。

没有改变原有脚本字节、链接、文字、控件、顺序、设置、业务逻辑或运行时。PWA 的 manifest、启动地址、worker、scope、订阅及缓存身份保持原样。新增链接使用绝对路径，不受 BOT/PWA 的 `base` 或相对 URL 影响。
