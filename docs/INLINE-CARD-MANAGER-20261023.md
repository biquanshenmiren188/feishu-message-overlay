# 卡片原地管理与一键屏蔽三端

网页 BOT/PWA 与 Windows v2026.10.23.4 的每张行情卡片提供「管理」「屏蔽三端」。管理留在当前页面或软件内，按交易所范围独立编辑电脑隐藏、电脑静音、行情卡片、手机推送，可新增、启停、删除；隐藏优先于静音。币种固定为当前卡片，其他条件仍在消息中台设置。

一键操作立即对当前币种全部交易所写入电脑隐藏、卡片隐藏及原始管理码手机方案屏蔽，不清除已有静音规则，不影响其他独立手机方案。沿用中台精确键 before/after 冲突检查、请求 ID 重试和操作日志；逐渠道显示结果，不宣称跨文件原子保存。网络结果不明时保留相同请求重试，不显示假成功。

桌面沿用 DPAPI 签名连接，经 publisher 的限定 coin-rules 指令访问 webpush 回环接口。只有当前已注册桌面公钥获得显式币种管理标记；其他读取客户端仍只读，不能借此 pin、修改发布配置或发布消息。未导出或替换私钥。
