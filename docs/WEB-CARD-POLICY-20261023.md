# 网页卡片推送接入消息中台

BOT 的网页卡片原来直接展示公开行情源，未应用中台行情卡片规则。现在已连接原始管理推送码的网页与桌面使用同一份 cards 设置、同一个服务端判定函数。币种、分所币种、整所、左/右腿与现货、OI、等级、类型和接收开关保持原语义；电脑隐藏/仅静音和手机推送独立。

- `GET /radar/push-test/api/card-decisions` 仅原始管理码可读，返回当前及短期保留卡片的 allow/hide 判定、规则版本、开关。无规则详情或用户身份输出。无令牌 401，其他手机方案 403，源文件异常 503。不会把网页轮询算为电脑在线，也不判定电脑消息。
- 浏览器每 3 秒同步，非前台停止轮询；未知卡片先等校验。规则首次未返回或超过 10 秒未成功同步则暂停展示，提示原因；401/403 立即清除该页旧判定。未连接管理码是有明确标识的公共浏览。切换推送码后不复用前码结果。
- 命中规则立即移除 DOM，包含旧卡片和滚动期间；模型保留原数据，解除后恢复。ACTIVE 数只包含显示卡片；另显示屏蔽张数。三端原始设置不改写。
- 卡片页“卡片规则”直达行情卡片设置；每张“管理”打开对应币种中台矩阵，加载完整规则后才可编辑。链接不写规则，管理页不跳入旧子页编辑器。PWA 保留原 scope。
- 拦截沿用行情卡片记录，按卡片身份、规则版本和动作去重；网页/桌面遇到同一卡片不重复记两条。

## 版本保留和验证

实际线上 BOT 是性能打包模块，并非根目录旧源码入口。`scripts/build-card-policy.py` 校验原 bundle SHA256 `8db43cfeb5cd754668bdd04ec5572720c2eecda947887a50599c9cc3949f06fb`，仅添加规则模块及四个渲染钩子；保留复制、GC Aster、混合腿、Unicode、SharedWorker URL 和原有摘要补丁。源码 basispulse.js 同步接入。新 bundle 使用内容哈希命名，BOT/PWA 两入口同时更新。

发布前发现 PWA fallback 仍引用旧 `bot-summary-874b3c8416fa.js`。逐字比较确认仅缺少网站已验证的两处 Aster GC 表达式；本次将 fallback 对齐当前网页 bundle 后一起接入规则，增加旧 PWA 入口与 bundle 的完整哈希保护。首次部署因该差异在任何线上修改前安全终止。

87 项 Python 完整测试在服务器隔离目录运行通过；61 项 Node 相关测试通过（最终空态修正后重跑 6 项卡片策略；其余卡片模型、复制和通知设置此前共 55 项通过）。覆盖网页不改变电脑心跳、不受电脑静音影响、与桌面相同左右腿/OI 判定、源错误、权限隔离、初始校验、失效、解除恢复和换码清理。三号 Chrome 的隔离真实 bundle：PTB 默认仅静音仍显示；中台启用卡片屏蔽后显示 ALT/IRYS、屏蔽数 1；删除该卡片规则后 PTB 自动恢复，静音保留。393px 检查无横向溢出。未以真实用户规则或人工推送测试。
