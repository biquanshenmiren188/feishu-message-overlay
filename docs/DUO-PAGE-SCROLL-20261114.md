# 大屏触控卡片跟随整页滚动

范围仅为 BOT 页 720–1199 CSS px 且主指针为 coarse、hover:none 的大屏触控布局。右侧卡片高度自然展开，取消独立滚动；消息历史保留原滚动容器。普通手机、鼠标电脑和其他页面不改。

本次仅追加 CSS 和更新入口样式引用，没有修改业务 JavaScript、报警服务、推送或设备数据。

## 验收

三号 Chrome，当前生产资源图加隔离合成消息和六张卡片：
- 820 px 触控：在右侧卡片触摸上滑，文档 scrollY 从 0 到约 285，卡片 scrollTop 为 0。
- 消息区触摸下滑：历史 scrollTop 从约 738 到 503，文档 scrollY 保持 0，进入 manual 阅读状态。
- 重新加载到最新，完整显示六条普通消息；卡片自然展开，无内部纵向滚动。
- 393/719 px 触控、820/1440 px 鼠标布局：修改前后主容器、消息面板、消息历史、卡片面板、卡片网格、卡片和操作栏的宽高、位置、字体、内边距和 overflow 完全一致。
- 以上为浏览器触控与尺寸模拟，不冒充实体 iPhone/Safari 验收；未发送手机通知。

部署从当前 release 克隆，仅增加哈希样式并更换 BOT 入口及 PWA fallback 的该样式引用。其他资源逐一比对；保护 manifest、worker、报警后端文件、配置、绑定、订阅和服务 PID。保留同名 backup 中的 fallback，回滚时仅恢复静态 current 与 fallback，先检查 current 仍属于本次发布。
