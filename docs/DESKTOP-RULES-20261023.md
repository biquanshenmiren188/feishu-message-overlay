# 电脑规则分离、失效卡片与静音标记

电脑消息现有两套同时生效的规则：仅屏蔽声音、屏蔽消息。各自保存币种、交易所、方向、等级和 OI 条件；隐藏优先于静音，接收总开关仍统一。旧设置迁入原动作对应规则，另一套为空，不新增用户过滤条件。行情卡片与手机规则仍独立。

PTB 已失效卡片仍出现的原因：服务端只判定 active 卡片，而桌面会保留消失卡片30秒。服务端现持久保存最小卡片字段，消失后保留判定60秒，包含30秒传输/轮询余量；规则修改及服务重启后仍重新评估。缓存文件为 desktop-card-cache.json，最多1100条判定，活动项优先。

Windows v2026.10.23.1 在仅静音消息标题最前面显示红框“屏”，包括普通和置顶消息。解除规则后移除标记，保留展开状态，消息不重响；手动关闭扬声器不冒充规则命中。功能源码185a6727cd7738b6116d22dd3bfa9b4ec5aab7fb。
