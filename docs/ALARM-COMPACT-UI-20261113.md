# 报警界面紧凑布局

用户确认电脑列表、手机卡片预览后授权上线。只调整报警页、编辑弹窗和历史页的视觉布局；共用导航、BOT、桌面小窗、报警后台不改。

- 桌面五列对齐：币种/来源、当前价、触发条件、状态/提醒、操作。普通行白底，持续报警红色状态，备用源明确标明。
- 手机 760px 及以下变为卡片：币种与状态在上，当前价与阈值并排，底部每30秒提醒与编辑/删除。
- 顶部页签与新增按钮同排，设备栏收紧；状态筛选由服务器状态派生，不产生独立行情判断。
- 表单保留既有精确币种解析、备用源复选框、默认启用、直接关闭、保存请求和重试逻辑。历史新增入口使用 `?new=1`，沿用原表单。
- CSS 仅限 `.alarm-page`，增量发布四个静态文件，不完整重建站点。

## 验证

- 14 项 JS 与 98 项 Python 原有回归通过（后端源码未改）。
- Chrome 3号（工具 ID4）隔离真实 Store 浏览器：六家交易所各新增、编辑、保存，共12次成功写入；包含 ETH、SOL、1000PEPE，精确原生symbol和备用源名单回显正确。重载保留。
- 无效负数价格被拦截；关闭编辑无放弃确认。报警中筛选能只显示触发规则；搜索、空筛选、历史查询、展开详情、新增入口通过。
- 320、393、768、1024、1440px 没有页面横向溢出或报警卡片内容截断；320×568 弹窗可滚动，保存按钮可见。
- 纯 UI 验收，不发手机测试通知，不打开桌面软件。浏览器手机视口不等于实体 iPhone Safari。

发布工具 `scripts/deploy-alarm-layout.py` 使用当前版本锁、源文件哈希、全静态树校验、原子切换及回滚；校验服务 PID、后台文件、报警配置和设备绑定不变。回滚仅恢复静态 current 链接，不恢复用户数据旧快照。
