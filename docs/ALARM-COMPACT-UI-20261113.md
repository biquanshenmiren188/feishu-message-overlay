## 2026-11-13 后续：缩小字号、稳定报价显示

用户反馈字体过大、价格/横杠反复闪烁，并要求行情判断放在后端。报价文字从18px降到14px，普通文字13px；手机输入框保持16px与44px触控高度。

根因：前端按报价时间戳加页面停留时间再次执行12秒过期，后端仍watching时也清空价格。线上只读45秒取样，Binance样本年龄1.963–11.149秒、状态持续watching，并有主源/OKX切换；旧前端在两次状态请求间可能先把价格清空。

- 前端采用服务器行情状态，12秒门限仅用于网页响应自身的连接时效。报价新鲜度、身份/单位、备用名单、阈值及30秒发送仍由原后端处理。
- 显示价格与对应来源一起更新，正常期间至少间隔5秒（轮询/渲染调度实测约5–7秒）；后台状态不节流，不平滑或改写实际价格。
- 真正断流或页面离线保留末次报价并明确标注，未取得过报价才显示横杠。缓存首次核实立即换成服务器报价，不把旧缓存当实时行情。
- 来源/末次提示固定一行占位，数值等宽数字、无动画；切码、删规则、改币种清理显示缓存。

验证：19项JS、98项Python通过。隔离网页模拟临界年龄、全断流与备用恢复；393px卡片高度和位置完全一致，320px无溢出，16px表单输入/可见保存按钮/关闭无确认通过。3号Chrome正式桌面连续30次1秒取样，无横杠，行高97.99px不变；手机393px连续12次无横杠/溢出，行高200.92px不变；320px无横向溢出。手机为浏览器视口验证，未进行新的实体手机推送。
