# 电脑消息与行情卡片接入消息设置

网页 `/radar/robot-push/settings/` 统一提供电脑消息、行情卡片、手机推送三组规则。BOT 蓝色推送设置按钮移除，入口使用顶部导航“消息设置”。手机保持既有独立方案、订阅、默认值和通知预览。

电脑消息命中币种、交易所、买卖腿、市场、等级或 OI 规则后，可选择只静音或隐藏消息。只静音仍进入原消息列表和置顶区域；混合批次有未屏蔽新消息仍可响铃。隐藏不播放声音，改规则恢复历史显示时不重新响铃。行情卡片规则独立控制左侧卡片显示；原始模型与复制内容保留，卡片原本没有提示音，因此不提供无效的静音选项。

Windows v2026.10.22.4 使用既有签名控制通道，每次请求附带 desktopRules 能力字段。publisher 经仅回环 `/internal/desktop-state` 获取判定；公众代理不暴露此路径。所有原始源消息、卡片和手机队列均不改写。未升级客户端保持原行为，升级后才实际应用规则。同步异常保留最后一次有效判断，连接恢复继续同步。

电脑策略及最近200条命中记录保存在 `/var/lib/radar-webpush-test/desktop-rules.json`，与手机 state 分离。原始管理推送码的认证身份可以读写；其他独立手机方案返回403。写入使用原子替换和版本冲突检查。签名桌面请求产生记录，包含频道、时间、原因、版本以及静音/隐藏动作，重复同步不重复记录。记录的是规则判定，不是人工确认已听见/看到的回执。开启接收总开关为关闭时，所有消息隐藏，即使规则动作选了静音。

组合以真实币种和方向解析；多组合消息任一组合命中按整条处理。无R值的专题仍检查币种和方向，但不会伪造R百分比；无法识别组合的普通文本只受接收总开关控制。OI 沿用 double-v1 精确合约来源和5分钟有效期；Aster/HY共享源缺失时执行已选缺失策略，不替代或补零。

验证：590项核心检查、完整桌面构建检查与四类更新回退测试通过；WPF真实控件验证静音仍显示、隐藏常规/置顶、混合批次声音、恢复历史不重响。另验证卡片过滤/恢复与消息独立。24项JS规则检查、Python桌面策略测试覆盖方向交集、持久记录、版本冲突、OI相等边界和专题解析；服务端候选还运行完整已有测试。浏览器隔离API验证独立保存与回读，不向正式手机发送测试消息。
