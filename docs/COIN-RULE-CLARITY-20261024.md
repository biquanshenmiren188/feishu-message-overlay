# 网页与桌面币种规则统一

2026-10-24，替代此前“未设置 / 已启用 / 已停用”的界面文案。

- 电脑推送：正常推送 / 仅静音 / 屏蔽。
- 行情卡片、手机推送：正常推送 / 屏蔽。
- 正常推送表示本币种所选范围没有屏蔽；仅静音保留电脑消息但不播放声音；屏蔽隐藏该渠道消息/卡片或阻止手机通知。其他范围和筛选条件继续生效。
- 网页和桌面卡片外部都只保留“管理”，弹窗内保留“屏蔽三端”。点选只改变草稿，必须点击保存，关闭放弃未保存的改动。
- 显式切换电脑模式时只移除同币种、同交易所范围的另一电脑规则；未经操作的旧停用和双开规则原样保留。卡片与手机旧停用记录显示正常推送，修改为正常推送时删除对应范围规则。
- 保存结果直接呈现三类渠道当前结果，操作记录区分规则变更与保存失败，避免把移除静音误显示成最终电脑正常推送。
- 批量仅静音清除目标范围的电脑屏蔽，批量屏蔽清除目标范围的仅静音；不影响其他币种/范围，批量仅静音不改卡片与手机。等待处理的保存结果按未完成显示，并用原请求重试。
