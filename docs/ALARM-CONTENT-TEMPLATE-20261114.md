# 报警内容直接编辑默认正文

打开“报警内容”时填入完整默认正文，已有自定义文字保留在前。用户直接修改文字、行序和提示语，保存的模板下次打开原样回显；清空恢复默认。

默认正文为 `{{行情来源}}`、`触发价格：{{触发价格}} USDT`、`{{触发原因}}`、`{{时间}}（北京时间）` 四行，有备注时增加 `{{备注}}`。字段在生成每一轮报警时展开，实际来源、换算后价格和北京时间不会被冻结成编辑时的旧数据。未填写的必要动态字段自动补齐；未知字段报错，替换只执行一次，不解释 HTML 或代码。

仅新内容操作携带 `alarmContentMode=template`；旧规则继续使用原发送方式，不迁移或重写既有规则。旧自定义内容打开时与默认正文合并，模板保存后不重复追加默认正文。模板最多 2000 字，容纳原有 1000 字自定义文本及默认字段；旧接口仍是 1000 字。普通报警编辑保留内容和模板标记。

一轮正文生成后保持不可变，多台设备使用同一份内容；轮中修改下一轮生效。备用源选择、倍率币换算、触发判断、逐设备 30 秒节奏和强提醒参数均保留。健康版本 15，新增 `alarmContentTemplate=true`。

验收：117 项 Python、3 项 JS 通过。新增三设备主源断流 → OKX 备用 → Bybit 备用、轮中修改、20/50/80 秒发送断言；1000PEPE 与反向倍率换算均覆盖模板正文。浏览器 3 号隔离环境 1440px / 393px / 320px 验证默认值、编辑保存、刷新回显、清空恢复默认与无横向溢出。未发送真实手机通知。

发布使用 `scripts/deploy-alarm-template.py`，先复制当前静态版本，再仅更新报警页 index 的文本与入口版本、app.js 和新增 content-template.js。当前线上导航及其他样式补丁保留；不覆盖旧完整页面。后台原数据副本启动验证、配置摘要比对、无关静态资产与推送服务 PID 检查均为发布守卫。回退只切换代码，不回写旧数据库。
