# 报警页面加载与独立记录页（2026-11-11）

## 用户可见变化

报警设置和报警记录成为两个独立页面，记录地址 /radar/robot-push/alarms/history.html。每页20条，可按币种/交易对精准搜索、发送状态和近24小时/7天/30天筛选。详情在展开时才请求。分页使用固定时间上界和稳定排序，刷新重置分页。设置页只取设备、规则与最近一条测试结果，不再读取/渲染100条历史。

初始化使用中性读取状态，设备区预留空间，认证完成前不显示未绑定或规则0；未连接仅在确认本地无身份后显示。报警页使用轻量 session.js 读取既有身份并链接推送中心，不再挂载完整Web Push设置、手机订阅同步或全页MutationObserver；其他页面身份组件不改。

状态读取并发合并，轮询在上一轮完成后再调度，后台页暂停，恢复前台立即同步。相同数据跳过render；规则行逐节点更新保留按钮/焦点。行情自然过期仍刷新显示。交易对缓存60秒，切码清除，空输入不显示全量列表。新增history/event API均复用原bearer鉴权和profile范围；原state默认完整响应保留兼容，settings用events=latest-test。
