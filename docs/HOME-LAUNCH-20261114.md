# 桌面启动、站内导航与详情遮挡

用户反馈：大屏桌面书签冷启动出现右侧系统栏，切到其他页再返回 BOT 消失；查看雷达打开另一层浏览窗口；组合页关闭按钮遮住费率数字。

已确认的代码问题：BOT 消息/卡片内部链接使用 target=_blank；820 px 组合标题栏实际 20 px，但固定关闭按钮 44 px，数字区从约 23 px 开始，产生交叠。冷启动旧入口 /radar/push-test/ 与导航 BOT /radar/robot-push/ 地址不同，manifest scope 和凭据声明没有回退。尚未在实体 iPhone 复现系统白边，不把桌面模拟当设备侧修复证明。

统一改动：所有八个 HTML 入口与 PWA fallback 接入同一 home-launch 脚本。在已安装模式下，同源 /radar/ 的新窗口链接改为当前窗口；外链、下载、修饰键和普通浏览器不变。仅 720–1199 px 大屏触控的旧桌面入口一次性 replace 到正式 BOT，保留 query/hash，不循环、不改 manifest 身份。主站新增独立 CSS，为触控组合标题栏预留 48 px，保留原样式和内容。

验收：12 项脚本行为测试；真实生产资源的隔离浏览器候选：旧入口自动到正式 BOT，查看雷达在当前 tab 到详情。393/820/1100 px 关闭按钮不再与费率行交叠，1440 px 鼠标布局未改。正式站发布前七个一级页面在 393/820/1440 px 共 21 次检查无页面横溢。主站 655 项测试、tsc 和 Vite 构建通过。

发布只克隆现行版本、修改八个入口及 fallback、增加两个哈希资源；其余文件逐项保留。保护 manifest、worker、报警后端文件、规则/绑定/订阅摘要和服务 PID；不发送手机通知。已安装手机是否采用新入口并消除系统白边需要一次真实冷启动确认，若仍出现须继续设备端诊断，不能声称该项已验收。
