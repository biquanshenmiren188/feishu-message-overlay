# 手机码权限、公共卡片与规则恢复

普通独立手机推送码调用 owner-only card-decisions 返回 403，旧网页把它视为尚未校验，所有卡片持续隐藏；设置页也允许填写不能保存的电脑/卡片草稿。这是权限状态处理错误，不能解释成用户已保存屏蔽。

- 仅服务器明确返回 403 时进入带标签的公共浏览，恢复公开行情卡片；不读取或应用所有者私有规则，三端管理按钮禁用。401、初次校验及 owner 判定超时仍暂停展示，避免意外绕过已连接的 owner 屏蔽；切换身份清空旧判定。
- 未载入有权限的规则时禁用该渠道输入、添加和保存，提示未读取而非“无屏蔽”。保留渠道切换、原始管理码连接及手机方案编辑。后端权限没有扩大。
- “放弃未保存修改”恢复当前渠道或当前电脑规则套的已载入快照，不写云端。
- “恢复本渠道全部接收”清除当前草稿的币种、交易所、腿、OI、等级、R 百分比和类型限制并开启接收，手动保存才提交；手机通知节奏与绑定保留。电脑只重置当前所选静音/隐藏规则套，同时开启共用接收开关；另一套筛选条件不变。

24 项 JS 检查通过，包括 403 公共模式、401 不降级、owner 屏蔽、恢复不修改原对象及通知绑定回归。隔离 Chrome 验证手机码看到三张公共卡片、无权限字段禁用，恢复草稿后服务端 revision=3/原币种和百分比保持，放弃可还原，手动保存后 revision=4/过滤清空。393px 实际 viewport 无横向溢出且新增按钮完整显示。
