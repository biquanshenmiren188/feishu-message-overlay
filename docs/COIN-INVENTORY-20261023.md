# 已屏蔽币种列表与一键屏蔽三端

消息设置默认打开“已屏蔽币种”，汇总已保存的币种和交易所范围，显示电脑隐藏、行情卡片、手机规则的状态，另行标记电脑仅静音。支持搜索、按渠道管理；原渠道里的币种行改为紧凑排版。管理中的编辑/删除仍是当前渠道草稿，需要保存，汇总列表只反映云端已保存状态。

“屏蔽三端”直接保存币种及指定交易所范围到电脑隐藏、行情卡片和当前手机方案；不触碰仅静音、其他条件、接收总开关、其他推送码或订阅。新增弹窗支持最多30个币种，选择仅加入当前渠道草稿或立即屏蔽三端。已有全交易所规则覆盖指定交易所时不重复添加；精确范围停用规则会重新启用。

## 服务端与失败行为

原始管理码才能访问GET coin-blocks和POST block-coins。其他码返回403，不放宽原有电脑管理权限。服务端在锁内读取最新设置并只合并币种字段，避免全表覆盖或前端旧版本覆盖。每次一键操作携带请求ID，先持久化意图，再分别保存渠道结果。重复请求复用结果；失败和中断允许同ID重试，已经成功的渠道不重新写入。两份状态文件不宣称跨文件原子事务，前端会明确逐端结果，不把部分成功显示为全部成功。

最近100次一键操作记录保存在desktop-rules.json的coinOperations，包含币种、范围、时间及各渠道保存状态；与既有真实消息拦截记录分开。不会伪造消息、回补拦截或发送测试通知。桌面规则普通保存也增加写入失败时的内存回退。

前端刷新/一键回读采用三方合并：已保存快照、当前草稿、新服务端设置。保留未保存OI、等级和其他币种修改；明确操作的成功目标同步为启用。手机号方案切换后丢弃旧操作显示，手机保存版本同步更新。
