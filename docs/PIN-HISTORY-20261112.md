# 置顶最近5条原样滚动（2026-11-12）

用户要求保留现有UI，只给置顶区增加滚动查看历史。最终实现没有新增按钮、没有新增历史弹窗，不更改普通推送或右侧卡片布局。

云端独立SQLite表按消息ID去重，只保留最新5条（含当前）。记录不会进入普通30条消息流、声音队列或手机通知发送链路。重启从数据库恢复；上线时保存当时仍有的置顶，早期已覆盖消息无法补回。云端持续接收不依赖网页或软件开启。本次不发布桌面软件包。

历史接口复用现行源成员校验；有网页个人码时应用该码规则，未知码401，读取失败503。规则读取不记录发送、不改心跳与屏蔽历史。前端在身份或规则失效时清除历史，原文继续使用既有查看方式。

现有卡片渲染器复用，置顶容器高度取最新一条原有卡片的自然高度。超过一条时独立滚动；wheel/touch不交给普通流处理。新置顶到达保留仍在5条范围内的阅读锚点，旧消息在上、最新在最下面；首次打开和刷新定位到底部。停在底部时跟随新置顶，往上阅读历史时保持原位置。历史文字只按原数据展示，混合窗口净均不借用其他组。

验证：接收器8项合成检查（含5条上限、去重、普通流隔离、重启和成员边界）；个人规则与历史HTTP接口9项检查；40项JS检查（保留原摘要/普通流行为）。实际生产资源图的Chrome合成回放：原版和候选置顶高度均106.098px，5条滚动时普通流位置不变；普通消息和新置顶到达保持历史锚点；既有原文打开/关闭可用；刷新恢复5条；320/393px无横溢。手机为浏览器视口，不是实体iPhone。
