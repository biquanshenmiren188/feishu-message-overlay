# 网站双边 OI 显示与筛选一致

用户明确要求网站使用双向（双边）OI。此前卡片渲染源站 leg.oi，筛选读取雷达标准 double-v1 USDT OI，两者来源、口径与采样时间不同，导致看起来低于门槛仍显示。不能据不同时间的数值直接断言固定倍数，更不能将所有交易所数值一律乘二。

现在网页卡片使用标准双边 OI。绑定方案时，card-decisions 同次返回用于判断的 OI 快照、门槛、口径与有效期；无门槛也读取双边值。公共浏览从只读 card-oi 获取当前公共卡片的市场数据，不包含账户规则、判定、历史或凭据。原鉴权接口权限不变；公共读取不写设置或卡片缓存文件。

显示与过滤共用 oi_value 的有效性检查。缺失/过期显示“—”，不回退到源站单边参考；现货腿不加 OI 门槛。双边 OI 的提示包含金额、适用门槛及时间。没有修改任何门槛、各所/币种覆盖、订阅或个人码；50 万仍是 50 万双边 USDT。没有改动原生桌面安装包。
